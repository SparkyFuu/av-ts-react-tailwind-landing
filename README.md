# Alejandro Valenzuela

Full Stack Developer focused on modern web products, internal platforms, cloud APIs, and polished user experiences.

I build React and TypeScript interfaces, NestJS backends, serverless AWS services, dashboards, corporate websites, and custom software for real teams and businesses.

[Portfolio](https://github.com/SparkyFuu/av-ts-react-tailwind-landing) - [LinkedIn](https://www.linkedin.com/in/alejandro-valenzuela-8780442a1/) - [GitHub](https://github.com/SparkyFuu)

## About

I am a developer from Santiago, Chile, currently working around the EnergyAsset ecosystem as Head of Technology and Information. My work sits between product, frontend engineering, backend architecture, and deployment.

I care about interfaces that feel clear, systems that can be maintained, and software that actually helps people operate better. My recent work includes multi-market websites, internal dashboards, serverless APIs, authentication flows, reports, data visualization, upload/media workflows, and FiveM server development.

---

## Current Focus

- Building production-ready React and TypeScript applications.
- Designing reusable UI systems with Tailwind, Radix UI, shadcn-style components, and clean state management.
- Creating NestJS backends with JWT, validation, PostgreSQL, Sequelize, S3, SQS, Lambda, and Serverless Framework.
- Shipping websites and software for EnergyAsset, EnergyAsset Management, TUPS, Hegemonik, SEF, Hermes Pisos, and Comunidad Hispano.
- Developing gameplay/server logic for FiveM roleplay communities.
